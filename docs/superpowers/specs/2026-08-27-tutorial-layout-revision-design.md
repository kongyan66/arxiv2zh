# arxiv2zh 教程页面排版与截图放大设计

## 背景

当前教程页首屏使用视口高度居中布局，导致标题上方出现大段空白，页面重心偏低。四张演示图片虽然采用 1600 × 1000 画布，但 Zotero UI 在画布中的占比较小，页面展示后操作区域和文字难以辨认。

## 目标

- 首屏内容从导航下方自然展开，消除无意义的垂直留白。
- 保留已确认的纵向产品展示结构，让演示截图成为首屏主要视觉。
- 四张演示图片全部紧裁并放大 Zotero UI，同时保持隐私安全内容。
- 提高后续步骤图片的桌面和移动端可读性。
- 保持现有中性 Apple 风格、深色模式、无 JavaScript 降级和可访问性。

## 首屏布局

首屏不再依赖全视口高度进行垂直居中。标题区采用紧凑的固定间距，从导航下方自然排列：

- 桌面端首屏上内边距为 36–48px，下内边距为 48–64px。
- 标题、说明、按钮和第三方服务声明之间压缩为稳定的内容间距。
- 产品截图宽度提升到 900–1040px，并保持居中。
- 首屏可以自然超过单个视口高度，不再为了露出下一节而牺牲截图可读性。

移动端保持上下结构，截图宽度占可用内容宽度。短屏设备不再把截图限制为 216px；320px 宽视口下截图至少使用减去页面边距后的完整宽度。

## 演示图片

四张现有 WebP 都重新处理：

- 保留当前虚构公开论文和隐私安全界面，不引入真实账号、Cookie、文献库或个人信息。
- 裁掉窗口四周及画布内部无意义空白，使关键 Zotero UI 占画布约 85%–92%。
- 根据各步骤保留必要上下文：安装图突出插件管理器，登录图突出账号入口，翻译图突出右键菜单，结果图突出中文附件和任务面板。
- 输出继续使用 WebP，保持清晰文字和合理文件体积。
- 为减少 HTML 与测试变化，最终画布仍保持 1600 × 1000；裁切后的内容缩放回该尺寸。

## 步骤区域

步骤区域继续使用交替图文结构，但提高截图权重：

- 桌面内容最大宽度从 1120px 提升到约 1240–1280px。
- 图片列占网格约 65%–70%，文字列约 30%–35%。
- 区域间距保持充足，但横向间隔从 72px 收紧到约 48–56px。
- 900px 以下切换为单列，让图片使用完整内容宽度。

图片容器保持 8px 以内圆角、轻边框和克制阴影，不增加装饰卡片、渐变或多余背景元素。

## 响应式与可访问性

- 保持固定断点，不使用按视口连续缩放字号。
- 保持图片固有宽高、响应式宽度和自动高度，避免变形或布局偏移。
- 导航、键盘焦点、Escape 关闭菜单、深色模式、减少动画和无 JavaScript 降级行为不变。
- 页面不出现横向滚动，文本与控件不重叠。

## 验收

自动检查：

- 运行 Prettier、ESLint、TypeScript 和全部单元测试。
- 保持教程图片路径、替代文字和尺寸属性契约。
- 校验四张 WebP 为 1600 × 1000 且可正常解码。

浏览器检查：

- 视口：1440 × 900、1024 × 768、390 × 844、320 × 568。
- 首屏不再出现异常大段上方空白。
- 演示 UI 在桌面和移动端明显大于当前版本，主要文字和操作区域可辨认。
- 页面无横向溢出，图片不变形，导航交互正常。
- 深色模式、减少动画和无 JavaScript 模式正常。

发布后检查 GitHub Pages 页面和四张图片资源均返回成功状态。

## 范围

本次只调整教程页面排版、响应式规则、四张教程图片及相关测试。插件功能、翻译流程、发布版本和其他项目文件不在本次修改范围内。
