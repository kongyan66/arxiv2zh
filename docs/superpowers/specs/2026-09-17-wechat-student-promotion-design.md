# arxiv2zh 学生向微信公众号推送设计

## 目标

面向高校学生，以官方、简洁但不生硬的语气介绍 arxiv2zh。正文控制在 500 个汉字以内，重点传达操作简单、中文 PDF 版式保留较好、基于大语言模型翻译三个核心卖点，并引导读者查看教程与下载插件。

## 内容结构

1. 标题：突出“在 Zotero 中直接阅读中文 arXiv 论文”。
2. 导语：从学生阅读英文论文耗时、公式和图表不便对照的场景切入。
3. 使用流程：安装插件、登录服务、在 Zotero 中选中论文并提交翻译；用“三步”表达。
4. 核心优势：无需 API Key 或本地环境；尽可能保留公式、图表、引用和论文结构；基于大语言模型生成中文 PDF，并自动归档至原条目。
5. 结尾：说明兼容 Zotero 7–10，提供下载与图文教程入口。

## 配图安排

- 首图：插件图标或产品名称，配一句核心价值主张。
- 图一：安装插件界面，对应“安装即可用”。
- 图二：Zotero 中右键提交翻译，对应“三步操作”。
- 图三：中文 PDF 结果页，对应“版式还原”。

优先使用项目已有真实截图：`docs/assets/images/tutorial-install.webp`、`tutorial-translate.webp`、`tutorial-result.webp`。正文以“【配图：……】”给出公众号编辑器中的插图位置。

## 事实与措辞边界

- 不使用“零门槛”“完美还原”“翻译绝对准确”等无法保证的表述。
- “版式还原好”写为“尽可能保留公式、图表、引用和论文结构”。
- “翻译质量高”写为“基于大语言模型，术语与上下文表达更自然”，同时避免承诺所有论文的结果一致。
- 明确当前仅支持 arXiv 论文，且论文需提供可处理的 LaTeX 源码；翻译服务及输出质量由第三方服务提供。

## 验收标准

- 正文不超过 500 个汉字（配图标记和链接信息不计入正文）。
- 语气符合官方项目介绍，学生无需技术背景即可读懂。
- 三个核心卖点均出现，并与项目 README 的功能边界一致。
- 至少安排三处真实配图位置，形成完整的图文阅读节奏。
