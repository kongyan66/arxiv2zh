# Security Policy

## Supported versions

Security fixes are provided for the latest published version of arxiv2zh. Users
should reproduce a problem on the latest release before reporting it.

## Reporting a vulnerability

Do not open a public Issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/kongyan66/arxiv2zh/security/advisories/new)
or email `caihua_sau@163.com` with the subject `arxiv2zh security report`.

Include the affected plugin and Zotero versions, reproduction steps, expected
impact, and any suggested mitigation. Do not send real passwords, session
cookies, personal access tokens, private papers, or unredacted Zotero databases.

The maintainer will assess the report and coordinate disclosure when practical.
No fixed response or remediation time is promised.

## Scope

Relevant reports include unintended disclosure of Zotero data, overly broad
cookie access or deletion, unsafe download handling, privilege misuse, and
dependency or release-pipeline compromise.

Availability, output quality, and account policies of hjfy.top or other
third-party services are outside this project's control. Vulnerabilities in a
third-party service should also be reported to that service's operator.
